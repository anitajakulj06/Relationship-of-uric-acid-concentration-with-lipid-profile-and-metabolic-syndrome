# Uric acid, lipid profile and metabolic syndrome — analysis code

Statistical analysis code for the study:

> Jakulj A. *Correlation of uric acid concentration with lipid profile and metabolic syndrome: a retrospective cross-sectional study.*

The script `analiza.py` reproduces every number reported in the Results section
(descriptive statistics, Spearman and partial Spearman correlations with
bootstrap 95% confidence intervals, Steiger's z-test, group comparisons and
hierarchical multiple linear regression).

## Data availability

The patient data are **not included** in this repository because of patient
privacy restrictions. They are available from the corresponding author on
reasonable request.

To allow the code to be run end-to-end, the repository contains
`primjer_podaci.xlsx`, a **fully synthetic** dataset with the same column layout
as the original data table. It was generated by `napravi_primjer.py` from simple
parametric models, and no value in it comes from a real patient. Results obtained
with it are for demonstration only and do **not** match the published results.

## Requirements

- Python 3.11 or newer
- Packages listed in `requirements.txt` (pandas, NumPy, SciPy, statsmodels, openpyxl)

Tested with Python 3.13, pandas 3.1, NumPy 2.5, SciPy 1.18, statsmodels 0.15, openpyxl 3.1.

## How to run

```bash
# 1. (optional) create a clean virtual environment
python -m venv venv
venv\Scripts\activate          # Windows
# source venv/bin/activate     # macOS / Linux

# 2. install the packages
pip install -r requirements.txt

# 3. run on the synthetic example
python analiza.py --podaci primjer_podaci.xlsx

# or on the original data (available on request)
python analiza.py --podaci tablica_unos_podataka.xlsx --sheet Podaci
```

The script prints all results to the console (about one minute, mostly due to
5,000 bootstrap resamples per correlation). The random seed is fixed
(`SJEME = 42`), so repeated runs on the same data give identical results,
including bootstrap confidence intervals.
